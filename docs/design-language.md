# Delta Comic 设计语言

来源：`/Users/wenxig/Documents/delta-comic/docs` 下 6 张设计参考图（hot-1、main-1、content-1/2/3、user-1），覆盖热门流、推荐流、视频详情、漫画详情（简介/评论）、我的页与明暗双主题。本文是 `ui/*` 插件实现组件时的唯一视觉基准。

## 总体气质

- 深色移动端风格为基准，明暗两套主题完全同构（同一布局、同一组件，仅 token 切换）。
- 品牌粉承担全部"交互语义"，浅蓝承担"工具语义"，两者不混用。
- 内容优先：图片区域尽量大，文字信息分层克制，图上信息用渐变或阴影保证可读性。

## 色彩系统

以 CSS variables 形式落为 token，命名前缀 `--dc-`：

### 品牌色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--dc-brand` | `#FF6699` | 主品牌粉：激活 Tab 文字与下划线、关注按钮、FAB、确认按钮、区块标题、等级徽章、tag 文字、进度条填充、播放进度 |
| `--dc-brand-strong` | `#FB7299` | 强调场景（按钮描边、hover 加深） |
| `--dc-brand-muted` | 粉的低透明度变体 | 回复 chip 背景、tag 底色等弱化场景 |

### 语义辅助色

| Token | 值 | 用途 |
| --- | --- | --- |
| `--dc-tool` | `#4FC3F7` | 工具类图标描边：我的页快捷入口、勋章/成就图标 |
| `--dc-warning` | 黄色系 | Dialog 警示感叹图标 |

### 中性色（深色主题）

| Token | 值 | 说明 |
| --- | --- | --- |
| `--dc-bg` | `#121212` 级近黑 | 页面背景 |
| `--dc-surface` | `#1E1E22` 级略浅面 | 卡片、Dialog、输入框底 |
| `--dc-media-bg` | 纯黑 `#000` | 媒体 letterbox 区（详情封面/播放器） |
| `--dc-text-primary` | 白 | 主文字 |
| `--dc-text-secondary` | 灰 | 次要文字、meta、日期、副标题 |
| `--dc-divider` | 低对比细线 | 列表分隔线 |

### 中性色（浅色主题）

页面纯白；搜索框浅灰填充 + 浅灰描边；主文字黑、次要灰；其余同构。

## 排版

- 字体系统 sans-serif 一套到底。
- 层级：
  - 区块标题（SectionHeader）：加粗大字，品牌粉色
  - 卡片/详情标题：14–16px 中等偏粗，支持多行与展开收起
  - 正文/评论：常规行高宽松
  - meta 信息（浏览量、日期、时长）：12px 灰
  - 统计大数字（我的页）：白色大号数字 + 小号灰色标签

## 形状

| 元素 | 圆角 |
| --- | --- |
| 搜索框 | 全胶囊（pill） |
| FAB | 圆角方形，约 16–20 |
| 卡片图/Dialog | 8–12 / 12–16 |
| 按钮 | 全胶囊（关注按钮、输入框） |
| tag chip | 小圆角描边 |

## 图标风格

- 常规导航/动作：线性描边图标，单色继承文字色。
- 我的页快捷入口与成就类：浅蓝色（`--dc-tool`）描边几何风格。
- 更多操作统一竖三点 `⋮`，置于卡片作者行与列表行尾部。

## 布局模式

### Shell 结构

```
TopBar（头像 + 胶囊搜索框 + 扫码 + 公告）
SecondaryTabs（横向滚动二级 Tab，激活 = 粉字 + 粉下划线）
Waterfall（双列瀑布主体）
BottomNavigation（5 槽，中央凸起粉色圆角方形 FAB）
ModalHost（顶层弹层）
```

底部导航激活项为品牌粉，非激活灰；中央 FAB 高于导航栏上沿。

### 媒体 letterbox

详情页封面/播放器区域固定纯黑背景，内容居中 letterbox 显示，控件悬浮其上（返回、home、画中画、全屏、进度条、播放按钮、@作者水印）。16:9 视频直接铺满该区。

## 设计原则

1. **粉色即交互**：所有可点击、激活、进行中的视觉信号一律品牌粉；工具/收纳类入口一律浅蓝。
2. **图上信息必须可读**：overlay 文字配渐变遮罩或半透明深色徽章。
3. **同构双主题**：任何组件先做深色基准，再映射浅色 token；禁止出现只在单一主题成立的布局差异。
4. **媒体区独立于主题**：letterbox 区域恒为纯黑，不受主题切换影响。
5. **信息密度分层**：标题 > 作者/meta > 计数，三级字号递减且后者恒为次要灰。
